# Wanderful Pages

create a website for travel. log in/sign up buttons on top right, password matcher to make sure the passwords match (first time, then confirm). make it aesthetic and pretty. there should also be a log out button when i'm signed in. when signed in, if i click my profile on the top right, i should have a dropdown that shows settings and dark or light option. if i click settings, it should open a popup (blur the background whenever a popup shows throughout the website, for images too when i click them to see full thing). in that popup, it should show the option to change profile picture, manage accounts (delete or add or change account from current one), and change username. also, for log in screen when i want to log in, it should show a forgot username or password option and to reset it (don't make it too complicated).

Sections:

1. Gallery - this should have a nice header and then a full aesthetic and beautiful section for showing the images uploaded from different log in's. It should show the image i upload in the upload section and title but when i click on the image, it should have a popup that shows more (image on left, the on the right, title in bigger font, and then description and a pin emoji with the location i put in the upload section next to the pin emoji (small and somewhere convenient). there should be a search bar here to search for locations/titles/descriptions. also have date of upload, account name with the profile picture. NO option to delete any other than the one's created from the account currently logged into.

2. My Gallery - same as Gallery section, but just have the images of the account i'm logged in as. search bar, fonts, and all that should be the same. this doesn't need the account name with profile pic, just the date and upload and description and location. and title. options to delete should be there as well.

3. Upload - this section should have the option to upload one or multiple images, description, location, and title. also, if not logged in, automatically open to the log in screen.
